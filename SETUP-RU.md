# Как опубликовать презентацию

Вся презентация и живая синхронизация уже подготовлены. Аккаунты лучше подключать в вашем обычном браузере, а не во встроенном браузере Codex.

## Перед запуском

1. В обычном браузере войдите в [GitHub](https://github.com/).
2. В обычном браузере войдите в [Supabase](https://supabase.com/dashboard/).
3. В Supabase создайте проект на бесплатном плане: [database.new](https://database.new/). Выберите европейский регион и сохраните пароль базы данных. Дождитесь, пока проект будет полностью готов.

## Авторизация GitHub

Откройте PowerShell и выполните:

```powershell
gh auth login --hostname github.com --git-protocol https --web --clipboard
```

Если окно входа открылось не в том браузере, откройте в обычном браузере `https://github.com/login/device` и вставьте показанный в PowerShell одноразовый код.

## Запуск автоматической настройки

В PowerShell выполните:

```powershell
Set-Location -LiteralPath "H:\gamification\gamification-prototype"
powershell -ExecutionPolicy Bypass -File .\go-live.ps1
```

Скрипт попросит:

- название публичного репозитория — можно просто нажать Enter и оставить `gamification-live`;
- `Project ref` из Supabase: **Settings → General → Reference ID**;
- войти в Supabase CLI — если потребуется токен, создайте его на `https://supabase.com/dashboard/account/tokens` и вставьте прямо в PowerShell;
- `Publishable key`: откройте в проекте Supabase кнопку **Connect** и скопируйте именно **Publishable key**, начинающийся с `sb_publishable_`.

Не копируйте в презентацию `Secret key` или `service_role` key.

В конце скрипт напечатает две ссылки и код ведущей. Код также сохранится локально в `presenter-code.txt`; этот файл исключён из Git и не будет опубликован.

## Проверка перед выступлением

1. Подождите 2–5 минут после первой публикации GitHub Pages.
2. Откройте ссылку аудитории в обычном приватном окне или на телефоне.
3. Откройте ссылку ведущей в обычном окне и введите код из `presenter-code.txt`.
4. Нажмите **Reset session**.
5. Проверьте переход на следующий слайд, горизонтальный слайдер и галереи.
6. На интерактивном слайде нажмите **Show an example** со второго устройства. Новый пример должен появиться у всех, а на нажавшем устройстве — таймер на 60 секунд.

Бесплатного тарифа Supabase достаточно, пока одновременно подключено не более 200 зрителей. Бесплатный проект может быть приостановлен после недели без активности, но для презентации через два дня это не проблема.
